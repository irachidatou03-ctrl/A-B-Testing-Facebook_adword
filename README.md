A/B Testing: Facebook Ads vs. AdWords

This project compares the performance of Facebook Ads and Google AdWords using A/B testing.
The analysis identifies which platform performs better in terms of:

Click-Through Rate (CTR)

Conversion Rate

Cost Per Click (CPC)

Python was used for data cleaning, metric calculations, visualization, and statistical testing.

📊 Key Results

Facebook has higher CTR (2.28%)

Facebook has higher Conversion Rate (32.70%)

AdWords has cheaper CPC ($2.27 vs. $4.31)

All differences were statistically significant (p < 0.001)
